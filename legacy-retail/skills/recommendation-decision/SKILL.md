# 商品推荐决策

从输入的候选列表中最多选择 3 个商品。

- 先匹配客户明确需求，再考虑评分等次要信号。
- MCP 结果只能作为补充上下文。
- 不得创造商品 ID、价格、库存、活动或优惠券。
- 没有合适候选商品时返回空数组。

输出一个 JSON 对象：

- `recommended_product_ids`：按推荐顺序排列的候选商品 ID 数组。
- `decision_summary`：简洁说明排序依据。
